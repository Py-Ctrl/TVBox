# TVBox / 影视仓 资源线路合集

<h3 align="center">精心收集的优质线路，持续更新维护</h3>

## 订阅地址

| 应用 | 地址 | 说明 |
|---|---|---|
| TVBox | https://tvbox.zpd.dpdns.org/tvbox | `{"sites":[{key,name,type:1,api}]}` |
| 影视仓 | https://tvbox.zpd.dpdns.org/ysc | 线路清单 `{"urls":[{name,url}]}` |
| 聚合 | https://tvbox.zpd.dpdns.org/agg | 与 `/tvbox` 相同，sites 聚合 |

根路径 `https://tvbox.zpd.dpdns.org/` 等同 `/tvbox`。

## 使用说明

1. 复制上表对应地址
2. 在 TVBox / 影视仓的配置地址栏粘贴
3. 点「确定」等待加载

## 仓库文件

| 文件 | 内容 | 使用方 |
|---|---|---|
| `tvbox.json` | 线路清单 `{"urls":[{name,url}]}` | TVBox（`/tvbox`） |
| `ysc.json` | 完整配置 `{spider,sites,lives,parses,flags}` | 影视仓（`/ysc`） |
